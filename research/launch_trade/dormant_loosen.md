# 冷门启动两组门槛微调（2026-10-27）

用户问题：IRYS_USDT 2026-10-21 14 点后开始拉升（之后三天涨约 7 倍），两组冷门参数都没报：现行一组 14:55 15 分钟涨 7.77%，
只差涨幅门槛 8%；慢启动 16:02 60 分钟涨 10.09%，只差后半窗口成交额占比 0.46（门槛 0.5）。要求先回测再决定是否放松这两项。
脚本：`dormant_loosen.py`。

## 一、预先写定的口径与判据（跑数前写下，之后不改）

### 1. 两个问题，分开检验

- **A 现行一组的涨幅门槛**：`config/default/dormant.yaml` 顶层各项（W15、成交额 ≥ 2 万、≥ 8 分钟有成交、单分钟 ≤ 5%、实体占比 ≥ 0.6、
  涨前波动 ≤ 0.5%、倍数 ≥ 10、最后一分钟 ≥ 1 千、后 8 分钟占比 ≥ 0.4、冷却 60 分钟、第 N 波步长 3%），只改涨幅 C ∈ {7.0%, 7.5%}，
  对照 C = 8%（现行）。
- **B 慢启动一组的后半成交额占比**：`dormant.slow` 各项（含跟踪补报 5%/240 分钟），只改 L ∈ {0.40, 0.45}，对照 L = 0.5（现行）。

只考察这两项，候选族就是上面 4 个变体；不顺带调别的门槛。逐分钟按检测器口径直接实现（含冷却、第 N 波、跟踪补报），
条件与特征沿用 `dormant_slow.py`（B3 与 W60 抽取），不改的一组用现行值即可与 `dormant_slow.md`、`dormant_waves.md` 对拍：
A 的对照应为开发期 0.435、2.44 条/天；B 的对照（含补报）应与 `dormant_waves.md` 5%/240 的第 1 波加补报一致。

### 2. 指标

与 `dormant_slow.md` 相同：「准」= 提醒价之后 H 分钟内先涨到 +X、没有先跌到 −X，X ∈ {3%, 5%}、H ∈ {60, 240}，4 种设置平均，
所有提醒（含第 N 波、跟踪补报）都计；冷门启动行情（≥ 10%、≥ 20%，`dormant_solo` 的之字线）的早报分 Re（每段第一次提醒剩下的
对数涨幅比例，没报到为 0）与前半段召回，两种幅度平均。变体相对对照：准确率差 ΔP、早报分差 ΔRe、每天条数之比。
开发期 2021-09 ~ 2024-12，样本外 2025-01 ~ 数据末尾（2026-10-10）。

### 3. 选参（只用开发期；A、B 各一个）

限制：开发期 P(变体) ≥ P(对照) − 0.01，每天条数 ≤ 对照的 1.5 倍。满足限制的变体里取**最松**的一个（A 先看 7.0%，B 先看 0.40）；
都不满足就不采用。只有两个候选，不做 PBO。

### 4. 判据（全部满足才采用；没达标直接剔除、不降级、不改用另一个变体）

1. **样本外不更差**：P(变体) ≥ P(对照) − 0.01，4 种设置中至少 3 种不低于对照 − 0.01（点估计）。
2. **样本外非劣**：按周循环块自助法（块长 4 周、2000 次，两者同一组权重），ΔP < −0.02 的概率 < 0.05。
3. **样本外确实报得更多更早**：ΔRe > 0，且自助法下 ΔRe ≤ 0 的概率 < 0.05。
4. **可行**：样本外每天条数 ≤ 对照的 1.5 倍。

只报告不作判据：新增提醒（变体有、对照没有的提醒时刻）自身的准确率、前半段召回差、IRYS / JCT / DOOD 用真实检测器回放的变化
（本机数据只到 2026-10-10，例子用交易所 K 线另算）。

### 4. 结论

- B 通过判据，可以把 `config/default/dormant.yaml` 的 `dormant.slow.min_late_quote_share` 改为 0.4（代码默认值不动）。
- A 未通过（样本外准确率差 0.0003 过线），按规则不推荐；若用户知情后仍要，代价是现行一组每天多约 1 条、整体准确率约 −0.01。

## 三、采用（2026-10-27）

用户确认后把 `config/default/dormant.yaml` 的 `dormant.slow.min_late_quote_share` 从 0.5 改为 0.4；`DormantSlowConfig` 的代码默认值
（0.5）不动。现行一组的涨幅门槛维持 8%。
